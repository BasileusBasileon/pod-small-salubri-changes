# pod-small-salubri-changes
# Features:
- A Gamerule for the Third Eye:
  - Shown for everyone with a third level perk in Valeren or
  - Shown for every Salubri, always
- Caste system is always active. Nkulu Zao do not get a caste.
- If the Gamerule for Out-Of-Clan-Discipline costs is enabled, Obfuscate is now correctly In-Clan for Watchers instead of Fortitude
- Salubri with a caste now have a default penalty of 1 on the cost of Valeren perks of other castes. Others still use the system of increasing costs for paths depending on the order that perks are learned in.
- Disabled splat hostility with Fera if you have "Hun and P'o" trait so that you can actually do the "Reckoning for the War of Shame" decision.
- Made Salubri Primogen available if they're part of your Sect (Faith).
- Added the Blooding, making you able to become a Warrior if you're a Healer or Watcher, under the right circumstances.

## Installation
Copy `pod-small-salubri-changes` and `pod-small-salubri-changes.mod` into your `/Paradox Interactive/Crusader Kings III/mod/` folder.
